perf(build): 只编 arm64-v8a —— 容器编译省 native 编译时间与体积

## 现状数据（run 45607135986，总 230s）
  Build container APK            167s  (72%)
  Unit tests                      21s
  Cache Android SDK / Gradle      13s + 13s
  其它（checkout/keystore/发布）   ~16s

core:hook 的 externalNativeBuild 没有 abiFilters -> CMake 为默认 4 个 ABI
（arm64-v8a / armeabi-v7a / x86 / x86_64）各编一遍 native-hook.cpp。

## 改动
app/build.gradle.kts 的 defaultConfig 加 ndk { abiFilters += ... }：
  默认 arm64-v8a（真机唯一需要的 ABI）
  本地可用 ABI_FILTERS=arm64-v8a,armeabi-v7a,x86_64 覆盖

预期：native 编译时间约 1/4；APK 从 25.8MB 下降（少 3 份 .so）。

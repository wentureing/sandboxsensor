## 维护规则

1. **结论必须能落到代码**（`调研-索引.md` 每条标模块，否则不收录）
2. **过程与结论分开**：`changes/` 存计划与实际 diff，`records/` 存结论
3. **过时结论直接删**，不留"作为参考"
4. **每份文档首行写"解决什么问题"**
5. **同一主题的多次调查要合并**（本次已把 P28 的 5 篇合并为 1 篇）

## 维护规则

1. **结论必须能落到代码**：`调研-索引.md` 每条都要标模块，否则不收录。
2. **过程与结论分开**：`changes/` 存"打算怎么改 / 实际改了什么"，`records/` 存"结论"。
3. **过时结论直接删**，不要留在文档里"作为参考"（本仓库已删过 30 篇）。
4. **每份文档首行写"解决什么问题"**，不写"本文介绍了…"。

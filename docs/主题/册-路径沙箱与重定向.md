## 一、现行结论

| # | 结论 | 等级 | 证据/来源 |
| --- | --- | --- | --- |
| **P-a** | 路径有三层手段：① `VirtualContext` 直接返回沙箱/合成路径 ② 原生 GOT patch ③ Java `RegisterNatives`（默认关） | A | 代码 + `现状-hook摸底` |
| **P-b** | `File` 是**纯 Java 且分叉**：`list0/createDirectory0/...` 走 `UnixFileSystem`，`length/delete/renameTo` 绕去 `Linux.*` → 必须两层都 hook | A | 反编译 + 实测 |
| **P-c** | 默认配置下"双层不一致"：app .so 落沙箱，Java `File` 落宿主真实路径 | A | via 的 mkdir 落宿主实测 |
| **P-d** | 翻译**幂等**（沙箱路径不命中任何规则）⇒ 多层并存不会双重翻译；**新增规则必须重验幂等** | A | `verify-idempotent-translate` |
| **P-e** | 合成路径族（`syntheticDataDir`/`pathFidelity`）只为"报告类" API 服务；实测**对 WebView MIME 无效** | A | W37 |
| **P-f** | 内容目录用真路径是有效的（WebView `file://` 的 `content://`/真路径场景） | A | `架构-WebView假路径换真路径.md` |
| **P-g** | 豁免名单（via 零欺骗、仍隔离）是设计理念第三条的落地：**只误导不危害读写** | A | golden C9 + 实测 |
| **P-h** | **`file://` 的 MIME 由"路径是否含应用包名"决定**（详见「册-WebView与file-MIME」） | A | W-ext 四组 |
| **P-i** | 容器存储权限：只有 `MANAGE_EXTERNAL_STORAGE`（appops allow）生效；`READ/WRITE_EXTERNAL_STORAGE` 声明但 targetSdk 35 下**不授予** | A | `dumpsys`/`appops` |

## 二、已证伪 / 不要再试

| 路线 | 为什么 |
| --- | --- |
| 假 `dataDir`（让 `getDataDir()` 返回 guest 路径） | 变了 dataDir，WebView MIME 仍错（W37） |
| 靠"给合成路径"修 WebView `file://` | MIME 判定在 Chromium，合成路径只会更糟（含包名 ⇒ 嗅探） |
| 只 hook 一层（只 Java 或只 native） | `File` 分叉 + libjavacore 是系统库 ⇒ 必漏一半 |
| 把沙箱整体迁到外部存储（笼统） | 外部 `Android/data/<pkg>` 实测仍 `text/plain`（W-ext-private） |
| 改 `getOpPackageName()` 返回值 | 破坏 appops 归因（`checkPackage` 抛 SecurityException） |

## 三、待确认 / 可能错

| # | 事项 | 说明 |
| --- | --- | --- |
| 1 | NIO2（`UnixNativeDispatcher` 0/38）的真实危害 | 用户决定"暂不实现"，但未量化有多少 app 用 NIO 写宿主 |
| 2 | `readlink` 在 Java 层缺失的泄露面 | A 族未 hook ⇒ 可把沙箱路径换算回真实路径（`疑似缺陷`） |
| 3 | 路径经 Binder 传出（`FileProvider`/Intent 里的 `file://`）是否被系统侧解析成真实路径 | 未单独评估（所有 pathFidelity 方案共同风险） |
| 4 | `hiddenPaths` 无 native 精确匹配 | Java 隐藏、native 不知道（低优先） |

## 四、现行方案要点（目标相关）

| 场景 | 用什么路径 | 备注 |
| --- | --- | --- |
| 普通 I/O（`getFilesDir` 等） | 真路径（沙箱） | `contentPathsUseReal` 开关；C-dual 方向 |
| 报告类（`ApplicationInfo` 字段） | 合成路径 | 只为"像真机" |
| **WebView `file://` 内容目录** | **`/storage/emulated/0/<不含包名目录>/`** | W-ext-nopkg 定稿 |
| guest 自己拼 `Android/data/<guest>` | 靠 GOT patch / javaIo 兜底 | 真实文件系统里不存在该目录 |

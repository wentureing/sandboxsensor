## 五、读架构前必须知道的四个"坑"

| 坑 | 说明 |
| --- | --- |
| **① 名称骗人** | `NativeHookBridge` 是 `@Singleton`，但**每个进程一份**；Kotlin 规则表也是进程级的 —— "主进程注册" ≠ "全局生效" |
| **② 注册点 ≠ 生效进程** | 详见 `架构-注入时机审计.md`。`VirtualEngine.launch()` 是主进程的管理动作 |
| **③ 双轨沙箱根** | `app_virtual/`（`SandboxManager` 名义）vs `files/virtual/`（实际使用），判断路径以实测为准 |
| **④ 文档时间 ≠ 正确性** | 见 §零；代码是唯一的事实来源，其次是标注了核实基准的文档 |

## 四、读架构前必须知道的三个"坑"

| 坑 | 说明 |
| --- | --- |
| **① 名称骗人** | `NativeHookBridge` 是 `@Singleton`，但**每个进程一份**；它的 Kotlin 规则表也是进程级的 —— "主进程注册" ≠ "全局生效" |
| **② 注册点 ≠ 生效进程** | 详见 `架构-注入时机审计.md`。`VirtualEngine.launch()` 是主进程的管理动作，往里面写"环境设置"就会跨进程丢失 |
| **③ 双轨沙箱根** | `app_virtual/`（`SandboxManager` 名义）vs `files/virtual/`（实际使用）—— 上游遗留，判断路径时以实测为准 |

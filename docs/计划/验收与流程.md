## 七、验收标准

| 阶段 | 验收命令 | 判据 |

## 八、所有改动都必须走 `docs/changes/` 流程

按 `AGENTS.md` 的约束：**≥3 文件 / ≥50 行 / ≥2 模块** 的改动，
必须先落盘 `docs/changes/<日期>-<任务>.md`（含 diff 预览），等确认后再动手。

本计划中 **P0-2 / P1-1 / P1-3 / P2-* 全部触发这条约束**；只有 P0-1（1 文件 60 行）和 P1-2（纯新增）接近豁免线。

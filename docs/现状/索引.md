## 三、外部资料（联网查过的，按主题）

### 3.1 WebView 相关

| 主题 | 来源 | 结论 |
| --- | --- | --- |
| Robolectric 版本兼容 | [官方兼容表](https://robolectric.org/compatibility_table/) | 4.14 → API 21–35 / Gradle 8.10.2 / AGP 8.7.1（唯一匹配我们） |
| HTML 显示源码 | [火山引擎文章](https://www.volcengine.com/article/2750535) | Content-Type 必须是 `text/html`；`loadDataWithBaseURL` 的 MIME 参数；转义问题 |
| `WebResourceResponse` OOM | [WebView2 #4294](https://github.com/MicrosoftEdge/WebView2Feedback/issues/4294) | 大文件必须流式，不能 `ByteArray` |
| `shouldInterceptRequest` 卡死 | [腾讯云问答](https://cloud.tencent.com.cn/developer/ask/sof/112039725) | 同步 IO 会冻结 WebView，宿主侧要独立线程 |
| JUnit 报告 action | [mikepenz/action-junit-report](https://github.com/mikepenz/action-junit-report) | 不依赖 git，纯解析 XML + 建 check run（`dorny/test-reporter` 需要 git 根目录） |

### 3.2 Android 平台行为

| 主题 | 结论 |
| --- | --- |
| `Context.getDir` vs `filesDir` | `getDir(n)` → `<parent>/app_<n>`（与 `files/` **平级**）；`File(filesDir, n)` → `files/n`。功能等价，只是位置不同 |
| WebView 多进程 | Android 10+ 由 `webview_zygote` fork，应用层**无法关闭**（无 `ro.webview.multiprocess` 等属性） |
| `MANAGE_EXTERNAL_STORAGE` | 通过 MediaProvider 生效，**直接 `open()` 仍受 DAC 限制**（本轮踩坑点） |
| `/data/local/tmp` | `shell:shell 0771`，other 只有 `x`；adb push 的文件是 `644` → 其他应用**可读** |
| `/sdcard/Download` | adb push 的文件属主 `u0_a0 media_rw`、权限 `660` → 其他应用**读不到** |
| Kotlin 块注释 | **可嵌套**：KDoc 里写 `.../**` 会打开新注释 → `Unclosed comment` |
| logcat 单行上限 | 实测 **4033 字符**（不是文档说的 4076） |

### 3.3 CI / GitHub Actions

| 主题 | 结论 |
| --- | --- |
| `actions/checkout` 带 `path:` | 仓库被检到子目录，**根目录没有 `.git`** → 任何依赖 `git ls-files` 的 action 会失败 |
| `continue-on-error: true` | 步骤失败**不会**让 job 变红（p23 的 `19 failed` 但 job 全绿就是这么来的） |
| `dorny/test-reporter` | 需要 git 仓库根 → 与上一条冲突，改用 `mikepenz/action-junit-report` |

## 四、维护规则

1. **新增一条调研结论时**，必须同时填"落到哪个代码模块"，否则不收录（避免又变成"看过就忘"）。
2. **同类项目的结论要标"已确认 / 推测"** —— Gaia 的 WebView 机制目前仍是推测。
3. **外部资料只留结论 + 链接**，不复制全文（避免文档膨胀）。
4. 本索引与 `架构-总览.md` 配合看：**索引说"结论在哪"，总览说"代码怎么组织"**。

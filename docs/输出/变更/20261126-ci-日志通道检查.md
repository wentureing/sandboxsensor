# 变更：module-test 加入日志通道测试 + 假绿守卫

- 日期：2026-11-26
- 授权：用户「允许改动，加入日志的测试任务。我希望测试和其他 matrix 模块一样中途输出」
- 触发：`module-test.yml` 的 matrix 缺 `:core:common`，导致日志相关 9 条单测在 CI 里**从不执行**；
  2026-11-26 的 run `45737628896` 三个 job 全 success 但一个测试没跑（假绿）

---

## 一、目标

1. `:core:common` 进入 **matrix**（独立 job、并行、中途可见输出），与其它模块同构；
2. 新增**日志通道契约检查**（Kotlin `DiagFiles` ⇄ C++ `is_container_diag_path` 一致性、通道名唯一）；
3. 新增**假绿守卫**：解析测试 XML，`tests=0` 直接失败；
4. 保持"一次一个 dispatch"与现有缓存 key 不变。

### 3.1 matrix + 新增 step（`module-test.yml`）

```diff

+        module: [":core:common", ":core:virtualization", ":core:hook", ":core:sandbox"]
```

```yaml
      - name: Checkout lint tools (sensor repo)
        uses: actions/checkout@v4
        with:
          repository: wentureing/sandboxsensor
          ref: main
          path: sensor

          fetch-depth: 1

      - name: Diag channel contract (DiagFiles ⇄ native kMarkers)
        working-directory: container
        run: node ../sensor/tools/lint/check-diag-channels.mjs .

      - name: Assert tests actually ran
        if: always()
        working-directory: container
        run: |
          set -euo pipefail
          total=$(grep -ho 'tests="[0-9]*"' -r --include='*.xml' \
            "${{ matrix.module }}/build/test-results/testDebugUnitTest" 2>/dev/null \
            | sed 's/[^0-9]//g' | awk '{s+=$1} END {print s+0}')
          echo "module=${{ matrix.module }} tests=$total"
          if [ "${total:-0}" -eq 0 ]; then
            echo "::error::No tests executed for ${{ matrix.module }} (filter mismatch or skipped)"; exit 1
          fi
```

### 3.2 契约检查脚本（`check-diag-channels.mjs`）

- Kotlin 侧：解析 `DiagFiles.kt` 的 `const val X = "..."` 与 `fun f(...): String = "..."`，
  把 `$pid`/`${...}` 代入哨兵值 `123`，得到名字集合；
- C++ 侧：解析 `native-hook.cpp` 的 `kMarkers[]` 字面量；
- **失败**：C++ marker 在 Kotlin 名字集合里找不到（真漂移）；
- **警告**：Kotlin 有通道而 C++ 未列入（列出清单，提示补白名单，不阻塞）。

### 3.3 `DiagFiles.markers()`

```kotlin
/** 给 C++ `is_container_diag_path` 下发的标记（不以 / 开头的片段）。 */

    "-filtered.log",

```

## 四、风险

| # | 风险 | 缓解 |
| --- | --- | --- |
| 1 | 新增 toolkit checkout 失败（权限/网络） | `contents: read` 已够；失败时该 step 报错但不影响其它 matrix job |
| 2 | 「Assert tests actually ran」误报（模块确实没有新测试） | 只在该 matrix job 的模块路径下统计；`:core:common` 有 9+ 条，`:core:hook` 有 5 条 |
| 3 | 契约检查因 `markers()` 尚未被 C++ 消费而产生"警告噪音" | 警告不失败；下一批做 JNI 下发后自然收敛 |
| 4 | 两次 checkout 拖慢 job | 只在 `:core:common` job 上跑契约检查（`if: matrix.module == ':core:common'`），其它 job 跳过 |

## 一、`core:common` 的命名问题与处置

| 现状 | 问题 |
| --- | --- |
| 8 个模块依赖 `core:common` | "被普遍依赖"≠"有职责"。它同时装 **日志/开关**、**反射兼容**、**诊断通道** 三件事 |
| 叫 `common` | 必然持续膨胀（"不知道放哪就放 common"） |

**处置（分两步，不拆 Gradle 模块）**：

| 步 | 动作 | 为什么现在不做 Gradle 拆分 |
| --- | --- | --- |
| **1（本轮起）包内职责化** | `diagnostics/` 内集中"通道 + 转储 + 命名规范"，日志/反射暂不动包路径 | 改包名会牵动 8 个模块的全部 import（DebugTrace 36 处 + DebugFlags + 反射工具），一次机械改动风险高、收益低 |
| 2（将来）拆模块 | `core:log`（DebugFlags/DebugTrace）→ `core:diag`（diagnostics）→ `core:reflect` | 等包内职责稳定、依赖方向固定后再拆，届时只需改 build.gradle |

## 二、第 1 批改造：具名诊断通道（D1 的第一步）

**目标**：把"落盘"从各处 `File(...).appendText(...)` 收编到**一个类**，但**文件名与格式一字不改**。

| 文件 | 类型 | 内容 |
| --- | --- | --- |
| `core/common/.../diagnostics/DiagChannel.kt` | **新增** | 单文件通道：`append(line)`、超限清空（沿用 1.5 MB 阈值）、失败静默 |
| `core/common/.../diagnostics/DiagFiles.kt` | **新增** | 诊断文件**命名规范**（`debug-trace.log` / `checks.log` / `breadcrumb-<pid>.log` / `stackdump-<pid>.log` …）+ 清单查询 |
| `core/common/.../DebugTrace.kt` | 修改 | `FileLogTree` 内部改用 `DiagChannel`（行为不变） |
| `core/common/src/test/.../DiagChannelTest.kt` | **新增** | C1 追加 / C2 超限清空 / C3 写失败不抛 / C4 命名规范 |

**判据**：`debug-trace.log` 的内容格式与门禁不变（`DebugFlags.isDebugBuild()` 为假时不 plant）。

## 三、第 2 批（下轮）：探针接入

探针（主仓库 `probe/`，`ProbeRunner` 863 行）新增 **D 系列检测项**，把"诊断通道是否按预期产出"变成可自动判定的结果：

| ID | 检查 | 判据 |
| --- | --- | --- |
| D01 | `breadcrumb-<pid>.log` 存在且非空 | guest 生命周期记录已产出 |
| D02 | `checks.log` 行数 > 0 | 诊断路由已工作 |
| D03 | `stackdump-<pid>.log` 存在 | watchdog 转储已产出 |
| D04 | `files/*.log` 总大小 / 个数 | 通道总量合理（不爆盘） |
| D05 | `checks.log` 尾部 3 行 | 能直接看最后一条诊断 |

探针不依赖 `core:common`（独立 APK），按**文件名模式**扫描 `<guest filesDir>`，与 `DiagFiles` 的命名规范保持一致（两处各写一份，规则写进 `DiagFiles` 的 KDoc 作为唯一规范文本）。

## 四、容器测试流程（第 3 批）

```
probe-build（出探针 APK）
  → adb install -r 探针
  → CmdReceiver LAUNCH_ACTIVITY 启动 probe
  → CmdReceiver COLLECT_OUT / LIST_OUT（收集探针输出 + 诊断文件清单）
  → 判定：D01–D05 是否全部 PASS
```

## 五、风险与回退

| # | 风险 | 缓解 |
| --- | --- | --- |
| 1 | 改 `DebugTrace` 导致日志格式/门禁变化 | 行为逐字保持（`formatLine` 不动）；单测 C1–C3 覆盖 |
| 2 | 通道收编改文件名 | 本批**不改任何现有文件名**，只新增类 |
| 3 | 探针扫描不到 guest filesDir | 探针本身跑在 guest 内，`getFilesDir()` 就是沙箱；D01 用 `Process.myPid()` 拼文件名 |
| 4 | 回退 | `git revert <commit>`（每批一个提交） |

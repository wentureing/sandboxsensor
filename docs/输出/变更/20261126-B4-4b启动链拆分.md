## 一、目标

把 `VirtualApplicationManager` 里两个**被两条 bind 路径共用**的启动步骤搬到 `lifecycle/startup/`：

| # | 职责 | 现状 | 去向 |
| --- | --- | --- | --- |
| ① | **触发 Application.onCreate**（Instrumentation 优先、失败直调、Shizuku SecurityException 吞掉） | `callApplicationOnCreate`（60 行） | `startup/ApplicationOnCreateInvoker.kt` |
| ② | **构造 guest 的 ApplicationInfo**（metaData/GMS 注入、`v135` 路径保真分支） | `buildApplicationInfo`（58 行） | `startup/ApplicationInfoFactory.kt` |

**为什么选这两个（而不是 `bindApplication` / `bindViaFrameworkLoadedApk`）**：

- 两者的**依赖为零**（不读 `applications`、不读任何 VAM 私有状态），搬走是纯搬家；
- `bindApplication`（212 行）与 `bindViaFrameworkLoadedApk`（169 行）是**编排**，依赖 6 个 VAM 私有方法
  （`swapInStockInstrumentation` / `restoreInstrumentation` / `disableCheckJniForGuest` /
  `initContentProviders` / `resources` 注入 / `PluginProbes`），一次搬会同时改 6 处契约 → 留给 B4-4c
  （那时编排只剩"顺序"，才符合"一次两个职责"）；
- 搬完这两步后，`bindApplication` 里剩下的就是**纯顺序**，B4-4c 才有干净的边界。

## 三、逐文件改动预览

### 3.1 `ApplicationOnCreateInvoker.kt`（新）

```kotlin
object ApplicationOnCreateInvoker {
    private const val TAG = "VAppLifecycle"

    /** Shizuku 在 onCreate 里触发的 SecurityException：容器必须吞（缺跨用户权限）。 */
    fun isShizukuSecurityException(t: Throwable?): Boolean

    fun invoke(application: Application)   // 原 callApplicationOnCreate 的函数体
}
```

**顺手收敛（规则 18.2）**：原实现把"取 `cause.cause ?: cause ?: e` + 三条 `contains`"**复制了两遍**
（Instrumentation 失败一次、直接调用失败一次）。抽出 `isShizukuSecurityException` 后两处都调它，
判据只此一份。

### 3.2 `ApplicationInfoFactory.kt`（新）

```kotlin
object ApplicationInfoFactory {
    fun build(packageName: String, apkPath: String, virtualContext: Context): ApplicationInfo
}
```

搬运要点：`metaData` 解析（`getPackageArchiveInfo` + GMS `243431006` 注入）、
`isPathFidelityGuest` 分支（4 个字段换成合成路径）**逐字保留**。

### 3.3 `VirtualApplicationManager.kt`（改）

```diff
-    private fun callApplicationOnCreate(application: Application) { …60 行… }
+    private fun callApplicationOnCreate(application: Application) =
+        ApplicationOnCreateInvoker.invoke(application)
```

```diff
-    private fun buildApplicationInfo(packageName, apkPath, virtualContext): ApplicationInfo { …58 行… }
+    private fun buildApplicationInfo(packageName: String, apkPath: String, virtualContext: Context): ApplicationInfo =
+        ApplicationInfoFactory.build(packageName, apkPath, virtualContext)
```

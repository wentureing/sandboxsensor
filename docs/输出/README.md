## 一、子目录

| 目录 | 放什么 | 命名 |

## 四、`变更/` 的读法

每份 `<日期>-<任务>.md` 包含：目标 / 影响范围 / diff 预览 / 风险 / 回退 / 验证方法。
配套的 `.actual.diff` 是**改完之后**用 `git diff` 生成的真实 diff（`AGENTS.md` 的硬要求）。

**注意**：部分变更后来被回退了（例如 WebView 的 v137/v139/v140 链式补丁）。回退的文档已移入
`docs/archive/错误结论-2026-11/`，本目录只留**仍有效**或**需要保留决策记录**的变更。

## 五、`调研/` 与 `记录/` 的区别

| | `记录/` | `调研/` |
| --- | --- | --- |
| 结论状态 | **已实测定死** | 可能有待验证的推断 |
| 能不能当依据 | 能 | **不能直接当依据**，需回到 `记录/` 或 `现状/` 核对 |

如果你在 `调研/` 里看到和 `现状/README.md` 冲突的说法，**以 `现状/` 为准**。
